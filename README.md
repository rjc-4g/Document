# 開発ルールv0.1

## チャット
*  Slackのチームチャンネルを使用する

## 命名規則
* プロジェクト名、リポジトリ名ともに `yyyyMM(開始年月)-team-(a or b)` (例：202610-team-a)

## ソースコード管理
* GitHub
* プロジェクト開始時に各チームリーダーがリポジトリを作成する

## プロジェクト管理
* GitHub Projects上で管理する
* [テンプレート](https://github.com/orgs/rjc-4g/projects/8/views/2)を使用し、プロジェクトを作成する
* プロジェクト開始時に各チームリーダーがGitHub Projectsを作成する

## ドキュメント
* /docsに配置する

## ブランチ戦略
* 各チーム内で検討する
* mainブランチにはブランチ保護ルールを適用し、直接プッシュを禁止する（ただし/docsは除く）
